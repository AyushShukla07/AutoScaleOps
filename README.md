# AutoScaleOps 

A production-grade cloud-native platform demonstrating advanced DevOps,
Kubernetes, CI/CD, DevSecOps, and cloud efficiency practices.

## Architecture
- Microservices-based architecture
- Kubernetes orchestration
- Automated CI/CD pipelines
- Observability and autoscaling
- Secure and cost-optimized infrastructure

## Tech Stack
- Frontend: React
- Backend: Node.js (Express)
- Containers: Docker
- Orchestration: Kubernetes
- CI/CD: GitHub Actions
- Cloud: AWS
- IaC: Terraform
- Monitoring: Prometheus & Grafana
